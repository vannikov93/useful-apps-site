# Useful Apps Workshop — Learning System

This directory contains the operational self-improvement layer for the Useful Apps workshop.

## Files

- `13_CONTINUOUS_LEARNING_SELF_IMPROVEMENT_ENGINE.md` — authoritative v2 standard for evidence-calibrated continuous learning and self-improvement.
- `workshop-learning/LEARNING_LEDGER.md` — two-stage capture template for incidents, lessons, causal evidence, and effect verification.
- `workshop-learning/REUSABLE_PATTERNS.md` — promoted reusable patterns with applicability and staleness boundaries.
- `workshop-learning/ANTI_PATTERNS.md` — validated anti-patterns and safer alternatives.

## Operating rule

Experience → structured evidence → causal calibration → contextual recall → minimum reversible change → real validation → action closeout → appropriate promotion → verified effect.

Do not add additional learning infrastructure until real project data demonstrates a retrieval, scale, or automation bottleneck.
